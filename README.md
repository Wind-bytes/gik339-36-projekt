## Environment Variables

Detta projekt använder sig utav Unsplash API för att hämta bilder.

**Skapa** ett gratis [Unsplash utvecklar-konto](https://unsplash.com/developers) och lägg till din nyckel i:

.env -> UNSPLASH_ACCESS_KEY=***byt ut denna text mot din access nyckel***

Detta ska alltså göras i **.env** filen som finns i root directory **Om** du vill kunna se bilder.
